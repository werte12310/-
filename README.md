# 稷耳知识库

稷耳项目的公开知识库网站，面向粮库巡检、安全规范、项目资料和比赛演示。

## 在线地址

- 网站：https://werte12310.github.io/-/
- 仓库：https://github.com/werte12310/-

这是一个不依赖后台服务和 Coze 资源点的静态网站。即使本地电脑关机，公网网址仍然可以访问。

## 主要功能

- 全中文首页、智能问答、知识库和管理后台
- 知识条目、分类和标签管理
- 本地浏览器数据存储
- 中文关键词与片段检索
- 回答显示来源和相关度
- 支持导出和导入 JSON 备份
- 可选连接本机 Ollama 生成回答

## 使用方法

### 浏览和问答

1. 打开在线地址。
2. 在“智能问答”中输入粮库巡检、项目资料或安全规范问题。
3. 系统先检索知识库，再生成带来源的回答。

### 添加知识

1. 打开“管理后台”。
2. 填写标题、摘要、分类、标签和正文。
3. 点击“保存知识”。

### 备份和迁移

静态版数据保存在当前浏览器。换电脑或换浏览器时：

1. 在旧浏览器点击“导出备份”。
2. 在新浏览器点击“导入备份”。
3. 选择导出的 JSON 文件。

## 本地模型

在“管理后台”的“本地模型设置”中填写：

- Ollama 地址：`http://127.0.0.1:11434`
- 模型名称：`qwen2.5:0.5b`

本机 Ollama 可用时使用本地模型生成回答；不可用时自动降级为知识库检索回答。

## 数据说明

- 公开访客的数据保存在各自浏览器中，不会自动同步到其他电脑。
- 管理员修改后应定期导出 JSON 备份。
- 不要上传密钥、密码、身份证号或未脱敏的隐私资料。

## 部署方式

仓库使用 GitHub Pages 发布：

- 发布分支：`main`
- 发布目录：仓库根目录
- 入口文件：`index.html`
